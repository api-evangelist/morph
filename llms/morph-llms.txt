# Morph

> Morph is an Optimistic zkEVM Ethereum Layer-2 blockchain (chain id 2818) building consumer-facing infrastructure. It exposes an Ethereum-compatible JSON-RPC API with Morph-specific extensions, a Blockscout block-explorer REST/GraphQL API, an official JavaScript SDK, and an official AI Agent Skill / CLI covering wallet, DEX, cross-chain bridge, EIP-8004 agent identity, alt-fee gas, EIP-7702 delegation, and the x402 payment protocol. Backed by Pantera Capital.

This file is generated by the API Evangelist enrichment pipeline from the repo's apis.yml and artifacts.

## APIs

- [Morph JSON-RPC API](https://docs.morph.network/docs/build-on-morph/developer-resources/morph-json-rpc-api-methods/): Ethereum-compatible JSON-RPC 2.0 (eth_*, net_*, web3_*) plus morph_* methods. Endpoint https://rpc.morph.network/ — chain id 2818, no API key.
- [Morph Explorer API (Blockscout)](https://explorer.morph.network/api-docs): REST v2 + GraphQL over blocks, transactions, addresses, tokens, and contracts. Base https://explorer-api.morph.network/api/v2 — no API key.

## SDKs & Tools

- [@morph-l2/sdk (npm)](https://www.npmjs.com/package/@morph-l2/sdk): official JavaScript SDK — CrossChainMessenger, gas cost estimation.
- [morph-skill (CLI + Agent Skill)](https://github.com/morph-l2/morph-skill): official AI-agent CLI (scripts/morph_api.py) — wallet, explorer, DEX, bridge, identity, altfee, EIP-7702, x402.
